# Odwen — Warehouse Operations Management System

A web-based warehouse operations control tower and facility layout management system.

## Features
- **Network Overview:** Multi-facility monitoring across 8 regional warehouse hubs with live occupancy metrics and heat density indicators.
- **Equipment & Instrument Fleet Tracking:** 3D asset tracking for forklifts, pallet jacks, reach trucks, conveyor belts, barcode scanners, weighing scales, strapping machines, and dock levelers with active vs. idle allocation status.
- **Multistorey Warehouse Facility Layout:** Interactive 3D/2D rack floor map visualization (Floors 1–3, Rows A1–F8) with occupancy status and slot inspection hover tooltips.
- **Inward & Outward Journey Tracking:** Inbound receiving, staging, QC inspection, cross-docking, and dispatch workflow coordination.

## Tech Stack
- HTML5 / Vanilla JavaScript
- Tailwind CSS
- Responsive flex/grid architecture

## Local Preview
To run locally:
```bash
python3 -m http.server 3000
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
